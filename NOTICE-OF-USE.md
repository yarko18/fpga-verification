# Notice of project use

This notice applies to Software releases governed by the FPGA Verification
Commercial Reciprocity License 1.0.

Commercial, academic, non-profit, governmental, and other organizational or
organized project use may begin immediately. Send a private notice to
`yarko@proton.me` within thirty calendar days after use begins.

There is no required form. The notice needs only:

- natural person, legal entity, or organized project;
- Software version initially used;
- general, non-confidential project category; and
- contact name or contact address.

Do not send confidential or internal project names, customer names, source
code, product details, test data, results, architecture, credentials, personal
data, or other confidential information. If no legal entity is responsible for
the project, a generic project identifier is sufficient.

No prior approval is required. No annual or periodic confirmation is required
merely because the same use continues. A notice does not replace the obligation
to contribute covered changes and does not authorize sale or other commercial
distribution of the Software itself.

One notice is required for each project. Employees and other individuals
covered by a notice from the responsible legal entity do not send separate
notices for that project. Updating the Software in the same project does not
require another notice.

Notice information is handled according to `PRIVACY-NOTICE.md`. A role-based
contact address may be used instead of a person’s name.

Example:

```text
Subject: FPGA Verification use notice

Person, legal entity, or project: Example Organization
Software version: 1.x.y
General project category: software verification
Contact: engineering@example.com
```
